# ID Gallery — GitHub Pages + Supabase

Galería pública para mostrar IDs e imágenes. Solo el usuario creador puede publicar/eliminar.

## 1. Crear Supabase
Crea un proyecto en Supabase y copia Project URL + anon/publishable key.

## 2. Base de datos
En SQL Editor ejecuta:

```sql
create table public.items (
  id bigint generated by default as identity primary key,
  item_id text not null,
  name text,
  image_url text not null,
  storage_path text,
  created_at timestamptz default now()
);

alter table public.items enable row level security;

create policy "public can view items"
on public.items for select
to anon, authenticated
using (true);

create policy "authenticated can insert"
on public.items for insert
to authenticated
with check (true);

create policy "authenticated can delete"
on public.items for delete
to authenticated
using (true);
```

## 3. Storage
En Storage crea un bucket llamado `images` y márcalo como **Public**.

Para restringir las operaciones de Storage al usuario creador, crea políticas de Storage en Supabase. La forma más sencilla es permitir upload/delete para `authenticated`, y usar una cuenta de creador cuyo acceso no compartas.

## 4. Crear usuario creador
En Supabase > Authentication > Users crea el correo y contraseña que usarás en `admin.html`.

## 5. Configuración local
Copia `config.example.js` a `config.js` y rellena:
- SUPABASE_URL
- SUPABASE_ANON_KEY

`config.js` debe estar en el mismo directorio que `index.html`.

> No pongas nunca una service_role key ni una contraseña dentro del código.

## 6. GitHub Pages
Sube todos los archivos al repositorio y activa Settings > Pages > Deploy from branch > main > /(root).

La galería pública estará en `index.html` y el panel del creador en `admin.html`.

### Importante sobre seguridad
Las políticas SQL de ejemplo permiten que cualquier usuario autenticado inserte/elimine. Para una instalación realmente exclusiva del creador, usa políticas basadas en el email/UUID de tu usuario. Sustituye `TU_UUID` en estas políticas:

```sql
drop policy if exists "authenticated can insert" on public.items;
drop policy if exists "authenticated can delete" on public.items;

create policy "creator can insert"
on public.items for insert to authenticated
with check ((select auth.uid()) = 'TU_UUID');

create policy "creator can delete"
on public.items for delete to authenticated
using ((select auth.uid()) = 'TU_UUID');
```

Y para Storage aplica la misma restricción al bucket `images`.
